# Contributing a blueprint

## Layout

```
blueprints/<id>/
  meta.json        # identity (required) — "id" must equal <id>
  compose.yml      # services (required, unless kraft.json)
  blueprint.toml   # variables + routes + env + files (required, unless kraft.json)
  kraft.json       # escape hatch for complex apps (instead of compose+toml, never both)
  logo.svg         # (required)
```

`catalog.json` and `index.json` are generated by CI on merge — never edit them.

## meta.json

```json
{
  "id": "grafana",
  "name": "Grafana",
  "description": "Dashboards and visualization for your metrics and logs.",
  "version": "13.2.1",
  "logo": "logo.svg",
  "category": "analytics",
  "tags": ["analytics", "dashboards", "monitoring"],
  "links": {
    "github": "https://github.com/grafana/grafana",
    "website": "https://grafana.com/",
    "docs": "https://grafana.com/docs/"
  }
}
```

`category` is one of `backend|database|cms|mail|analytics|automation|other`.

## compose.yml

Restricted Compose: `image` (pinned — `latest` keeps the app unavailable),
`expose`, `environment` (`${VAR}` only for declared variables), named
`volumes`, `depends_on`, `restart`, `healthcheck`, `command`.

Forbidden (CI refuses): `ports:`, `container_name:`, `networks:` /
`network_mode:`, `privileged:`, host bind mounts, `build:`.
Routes are declared in `blueprint.toml`; the edge publishes them.

## blueprint.toml

```toml
[variables]
main_domain = "${domain}"        # minted hostname, derived at install
admin_password = "${password:32}"

[[routes]]
service = "grafana"
port = 3000
host = "${main_domain}"          # http, published on a domain

[env]
GF_SECURITY_ADMIN_PASSWORD = "${admin_password}"
```

Helpers: `${domain}`, `${password[:N]}`, `${base64[:N]}`, `${hash[:N]}`,
`${uuid}`, `${randomPort}`, `${email}`, `${username}`,
`${timestamp}`/`${timestamps[:date]}`/`${timestampms[:date]}`.
A plain literal is an operator-editable default. Every `${VAR}` used in
compose/env/routes/files must be declared in `[variables]`.

TCP services: `kind = "tcp"` with `mode = "publish"` (needs `expose:`) or
`mode = "internal"` (project network only, no `expose:` needed).

Generated files: `[[files]]` with `service`, absolute container `path`
(no `..`, no `/proc`/`/sys`), and `content` (256 KiB max, 20 files max).

## kraft.json

For apps needing setup commands, day-2 settings, file mounts beyond
`[[files]]`, built images, exact argv, or advanced connection outputs:
author the template directly in Kraft's `AppTemplate` shape instead of
`compose.yml` + `blueprint.toml`. Same validation applies.

## Review bar

- One app per pull request. Test the deploy from the PR preview before
  requesting review.
- Images pinned (`:latest` stays unavailable). Official upstream images only.
- Secrets are generated, never hardcoded. No credentials in `content:` blocks.
- `node build-scripts/compile.js --check` passes; CI conversion passes.
- A new app ships `available` only after a green end-to-end deploy.
